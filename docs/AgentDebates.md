# Agent Debates

A terse log of disagreements where Brian or an agent changed the other's mind, or Brian overruled an agent without persuading it. Newest first.

The goals are to learn what changes minds and to test judgment against later evidence—not agreement. For overrides, track whether Brian later regrets the decision and, separately, whether evidence supports it. An agent persuading Brian is a changed mind, not an override; an agent refusing or blocking his choice without persuading him is an override and belongs here too.

Format: `## Date — topic` (with agent and context), then `### Point` per disagreement with **Brian**, **Agent** and **Changed** or **Overruled** bullets. For testable claims, record predictions, probabilities and resolution criteria before the outcome; later append dated **Evidence** and **Regret** bullets when available. Never reconstruct prior confidence from hindsight. Compare predicted probabilities with observed frequencies across resolved claims; one outcome cannot establish calibration, and this selected log cannot measure overall accuracy.
